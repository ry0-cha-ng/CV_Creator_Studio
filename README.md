# CV Creator Studio

ClutchVault向けの定点ショート動画を、1つのプロジェクトから日本語・英語で書き出す
個人用Electronアプリです。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
npm run package:win
```

macOS用DMGはApple SiliconのMac上で `npm run package:mac` を実行してください。

## 現在の実装範囲

- ローカル保存先とプロジェクトJSON
- 自動保存、プロジェクト一覧
- 録画取り込み、ffprobe解析、FFmpegプロキシ生成
- 定点情報と日英テロップ編集
- T-STD（7シーン）Remotionプレビュー
- 中央切り抜き、ぼかし背景、ズーム、フリーズ、照準マーカー
- 日本語・英語のMP4、カードPNG、meta.json一括書き出し
- 同梱フォントによるオフライン動作
- BGMライブラリ（MP3・WAV・M4A・OGGの登録、重複検出、LUFS・波形解析）
- 入手元・クレジット・利用可能プラットフォームのライセンス確認
- T-STDのシーン別BGM音量、フェード、プレビュー・書き出し
- −14 LUFS調整、BGMなし版、BGM情報・クレジット付きmeta.json

音声機能の検証用ファイルは次のコマンドで再生成できます。

```bash
npm run generate:test-audio
```

カードの最終寸法・ブランド素材は、デザイン参照画像と正式素材の追加後に調整します。

## YouTube 予約投稿（自分専用）

アプリから非公開アップロード → YouTube Studio で不足項目を補完 → アプリで予約確定、が標準です。Google 接続がなくても、従来の手動投稿は使えます。

### Google Cloud 側の準備

1. 既存の YouTube 分析用プロジェクトを再利用できるか確認する。なければ作成し、**YouTube Data API v3** を有効化する。Analytics API は分析利用時の別設定。
2. OAuth 同意画面を設定する。個人 Google アカウントなら External を基本に、Testing では本人をテストユーザーへ追加する。
3. **Desktop app** クライアントを作り、アプリ設定の OAuth 欄にクライアント ID（必要ならシークレット）を入れる。架空の ID は埋め込まない。
4. アプリで「Google でログイン」（分析・読み取り）したあと、投稿するときは「投稿を有効にする」で再認可する。許可されたスコープだけが使われる。
5. Testing の更新トークンは通常 7 日で失効する。継続利用するなら公開ステータスや本人利用の検証例外を Google の現行案内で確認する。Production 化は審査済みを意味しない。

### Studio 側

カスタムサムネイル、Shorts 関連動画に必要な高度な機能、再生リスト、VALORANT のゲームタイトル、アップロード既定値を確認する。ゲームタイトル・Shorts カバー・関連動画・有料プロモーション・ブランド連携は初期版では Studio での手動確認が完了条件になる。

### 運用

予約済み表示を確認してから PC を閉じてよい。公開そのものは YouTube が行う。アプリの状態更新は起動・復帰・手動更新時。予約変更はアプリまたは Studio のどちらでもできるが、アプリへ戻ったら再取得する。このPCの接続解除では YouTube 上の予約は消えない。

検証用の短い動画と、余裕のある未来時刻を用意してから実API確認する。テスト動画の削除は Studio で本人が判断する。
